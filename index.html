The core idea

Instead of asking one LLM to "hack this", a Rust engine runs the methodology — it picks the specialist agents that fit what it finds, runs them in parallel, re-sends every claim over the wire, and has a second model check each finding before it's reported.

The LLMs are the hands; the harness is the discipline that keeps them honest. That's why it finds more and invents less than running a model directly.

The pipeline

Seven disciplined stages, every run

An engagement is a fixed methodology — not a single prompt. The engine drives each stage and gates the next on proof.

01

Recon

Maps the surface with real tools — curl, nmap, ffuf, JS-bundle route discovery.

02

Select

Picks only the agents whose preconditions match the recon — never blindly runs all 486.

03

Exploit

Specialists work in parallel ReAct loops — each must prove its claim with a tool receipt.

04

Wire-check

The harness re-sends every exchange through a scope-guarded replay engine.

05

Vote

A different model adjudicates each candidate — cross-model voting cuts false positives.

06

Chain

Confirmed findings chain into deeper impact — SQLi→RCE, SSRF→cloud — each stage proven.

07

Report

HTML · PDF · JSON · SARIF, with an OWASP / CWE / MITRE-mapped attack graph, secrets redacted.

It won't invent findings: every claim needs a receipt — raw tool output or a file:line.

What makes it different

Discipline you can audit

Four safeguards that are part of the process, not a flag you remember to set.

Wire-bound evidence

Every exchange an agent reports is re-sent by the harness itself through a scope-guarded replay engine and checked against recorded traffic. A claim the wire contradicts can't stand as confirmed.

  • Deterministic validators judge real response bytes, not the model's prose.
  • Per-CWE grading: SQLi that extracted nothing scores demonstrated 0, not a fake critical.
  • What can't be checked stays flagged unverifiable — never silently promoted.

Attack knowledge graph

The run is a typed graph of hosts, services, findings, credentials and impact — spanning web and the internal network. It directs the next move during the run, and is written to graph/ even with no database (Neo4j optional).

  • A graph checkpoint runs after recon, at validation, each chaining round and at the end.
  • Every edge marked confirmed / needs-validation / hypothesis, ordered by kill-chain stage.
  • Cypher + JSON export; choke_points finds the single edge that cuts the most paths.

Secrets never leak the report

Credentials the agents observe become $SECRET_n placeholders across every human-facing report — the same secret keeps the same placeholder, so an attack chain stays readable. Raw values live only in the run's vault, for re-testing.

  • Redaction is always on — report.md, html, json, sarif, pdf and findings.md.
  • Graph properties store salted fingerprints — never a raw secret, body or narrative.
  • Nothing about your targets leaves your machine unless you send it.

It reasons about uncertainty

NeuroSploit treats the target as partially observable — a POMDP. A belief world-model carries probabilities, an anti-hallucination gate forbids claiming exploitability while the belief is diffuse, and value-of-information decides scan-more vs. exploit-now.

  • Grounding gate: empirical for black-box/host/AI, symbolic file:line for white-box.
  • Evidence-graded CVSS from the FIRST v3.1 equation — the vector travels with the number.
  • Hash-chained audit trail, signed anchors, and a P1–P5 assurance manifest.

Quick start

Up and running in two commands

The installer sets up Rust if missing, builds the release binary, and links neurosploit onto your PATH.

install — Linux / macOS
# Linux / macOS (x64 & arm64)
curl -fsSL https://raw.githubusercontent.com/\
JoasASantos/NeuroSploit/main/setup.sh | bash

# Windows (PowerShell)
irm .../install.ps1 | iex
run — black-box
# just run it — the REPL asks everything
neurosploit

# black-box, subscription login (no API key)
neurosploit run http://testphp.vulnweb.com/ \
  --subscription --model anthropic:claude-opus-4-8 -v
